# Handover Skill

現在の作業状況を整理し、次のサブエージェントに引き継ぐための情報をまとめるスキルです。

## あなたの役割

ユーザーから `/handover` コマンドを受けたら、現在までの作業状況を整理し、次のサブエージェントが効率的に作業を継続できるよう引き継ぎ情報をまとめてください。

## 引き継ぎ情報のフォーマット

以下のフォーマットで引き継ぎ情報を出力してください：

```markdown
# 作業引き継ぎ情報

## 1. 元の依頼内容
[ユーザーからの最初の依頼内容を記載]

## 2. 作業状況

### 完了したタスク
- [完了したタスク1]
- [完了したタスク2]
- ...

### 進行中のタスク
- [進行中のタスク]: [現在の状態]

### 未着手のタスク
- [未着手のタスク1]
- [未着手のタスク2]
- ...

## 3. 変更したファイル
| ファイル | 変更内容 |
|----------|----------|
| `path/to/file1` | [変更の概要] |
| `path/to/file2` | [変更の概要] |

## 4. 重要な決定事項・設計判断
- [決定事項1]: [理由]
- [決定事項2]: [理由]

## 5. 注意点・制約
- [注意点1]
- [制約1]

## 6. 次のサブエージェントへの依頼

### 依頼内容
[次に実行すべきタスクの詳細な説明]

### 参照すべきファイル
- `path/to/important/file1`
- `path/to/important/file2`

### 期待するアウトプット
[次のサブエージェントに期待する成果物]
```

## 実行手順

1. **会話履歴を分析**: これまでの会話から、依頼内容・作業状況を把握する
2. **TodoListを確認**: 現在のTodoリストがあれば、その状態を反映する
3. **変更ファイルを特定**: git status や会話履歴から変更されたファイルを特定する
4. **引き継ぎ情報を生成**: 上記フォーマットに従って情報を整理する
5. **出力**: 整理した引き継ぎ情報をユーザーに提示する

## 使い方

### 基本的な使い方
```
/handover
```
現在の作業状況をまとめて出力します。

### 引数付きの使い方
```
/handover $ARGUMENTS
```
`$ARGUMENTS` に特定の情報や次のタスクの指示を含めることができます。

## 注意事項

- 引き継ぎ情報は、この会話を見ていない別のサブエージェントでも理解できるよう、十分なコンテキストを含めてください
- 機密情報（APIキー、パスワードなど）は含めないでください
- 不明点や曖昧な部分があれば、その旨を明記してください
